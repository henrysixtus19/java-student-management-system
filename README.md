# Java Student Management System

## Overview

The Java Student Management System is a desktop application built with Java Swing. It provides a graphical interface for managing student information, course enrolment, and academic grades.

## Features

* Add student records.
* Update existing student information.
* Delete student records.
* Search for students by ID.
* Select courses.
* Assign and manage student grades.
* Display student information in a table.
* Clear input fields.

## Technologies Used

* Java
* Java Swing
* Java AWT
* JTable and DefaultTableModel
* IntelliJ IDEA

## Getting Started

### Prerequisites

* Java Development Kit (JDK)
* IntelliJ IDEA or another Java IDE

### Running the Application

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Locate `StudentManagementSystem.java` in the `studentmanagement` package.
4. Run the `main` method or the configured application run target.
